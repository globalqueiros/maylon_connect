Olá,

Atualizamos novamente o Portal Connect com foco em PIX e Cartão (combinado).

Por favor, no servidor:
1) Faça deploy do código atual
2) Confirme no .env as chaves Stripe e BTG (ver lista abaixo)
3) Rode no MySQL o arquivo sql/usuario_beneficios_payments.sql (ignore erros de coluna já existente)
4) Reinicie o app (npm run build && npm run start / pm2 restart)

Chaves obrigatórias no .env do servidor:
- STRIPE_SECRET_KEY
- NEXT_PUBLIC_APP_URL (URL pública do site, ex: https://seudominio.com)
- BTG_CLIENT_ID, BTG_CLIENT_SECRET
- BTG_COMPANY_ID (ou BTG_SECRET)
- BTG_ACCOUNT_NUMBER
- BTG_PIX_KEY
- (recomendado) BTG_ACCESS_TOKEN / BTG_REFRESH_TOKEN se o BTG exigir

Depois, hard refresh (Ctrl+Shift+R) e valide:
1) Login
2) Benefícios → selecionar plano
3) PIX → Gerar QR de Autorização (precisa ter CPF no perfil)
4) Cartão → Pagar (formulário de cartão DENTRO do portal, sem redirecionar para o site da Stripe)

Se falhar, envie print + status Network de:
- /api/btg/pix/authorize
- /api/stripe/checkout

Obrigado.
